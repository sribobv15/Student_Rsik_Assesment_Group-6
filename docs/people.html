Group 6

This project was developed by Group 6 as part of the Datalogical Thinking course. All participating members contributed to the project's conceptualisation, group discussions, and key design decisions, including dataset exploration and feature selection. Individual responsibilities were divided to support the development of the algorithm, Python notebooks, website, and final submission.

Why divide work this way?

We divided responsibilities according to team members' skills and availability. This allowed us to organise code development, website design, file integration, and submission as manageable tasks while maintaining shared involvement in the project's overall direction.

How we collaborate

We use a shared GitHub repository to store project files and coordinate updates. Participating members contribute to group discussions about the project's concepts, feature choices, algorithm design, and website content.
