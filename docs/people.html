Why divide work this way?

Separating data analysis, algorithm development, website creation, and documentation allows team members to focus on manageable tasks. Shared reviews help connect these pieces and keep explanations consistent across the site.

How we collaborate

We use a shared GitHub repository to store project files and review updates. The team discusses feature choices, checks the algorithm's results, and coordinates the final website content together.
